# 2026中国服装行业大会 H5｜交付说明

移动端优先的单页 H5，用于大会会后精华传播：内容吸引点击 → 智能纪要证明价值 → 飞书与豆包工作建立品牌认知 → 客户主动预约咨询。

## 一、交付文件

| 文件 | 用途 |
|---|---|
| `index.html` | H5 页面本体（原生 HTML/CSS/JS 单文件，自包含，含内置数据兜底副本） |
| `h5-data.json` | **可替换数据文件**：议程、嘉宾、摘要、妙记片段、链接、视频地址均在此维护，部署后优先读取 |
| `README.md` | 本说明：部署、替换、埋点、验收与待补素材 |

页面结构：Section 01 首屏（大会KV横幅）→ Section 02 内容选择（3 标签滑动切换）→ Section 03 摘要抽屉（含妙记卡片与片段链接）→ Section 04 飞书能力说明（深色）→ Section 05 从记录会议到推进工作（深色）→ Section 06 带走资料与预约咨询（深色）。

## 二、部署说明

1. 将 `index.html` 与 `h5-data.json` 放在**同一目录**上传至静态服务器 / OSS 即可；手机浏览器与飞书内打开均正常。
2. 数据读取机制：页面优先 `fetch('h5-data.json')`（部署后可只换数据文件、不改页面）；若该文件不可达（如本地双击打开），自动使用 `index.html` 内置兜底副本。
3. 建议开启 HTTPS；所有外链均为 HTTPS，并在当前窗口打开（视频弹层除外）。

## 三、真实纪要生成后的替换说明（核心机制）

**只改 `h5-data.json` 和图片素材，不改页面结构。** 步骤：

1. 将 `"status": "placeholder"` 改为 `"status": "live"`。
2. 逐场替换 `tracks[].sessions[]` 中的：
   - `speakers`：该场演讲嘉宾数组，**每位嘉宾拥有独立的纪要跳转数据**：
     `[{ "name": "姓名", "role": "单位/职务", "minutesUrl": "该嘉宾飞书完整纪要链接", "minutesFragments": [{ "title": "片段名", "time": "时间点", "url": "链接" }], "placeholderImage": "该嘉宾纪要封面图" }]`
     - 同场多位嘉宾合并为一个 session，页面呈现为一张卡：标题只显示一次，每位嘉宾一行、各自"查看纪要"入口，点开即见该嘉宾独属的纪要卡片与妙记片段链接；
     - 嘉宾级字段留空时自动回退到 session 级同名字段（兼容旧数据）；
   - `summary`：该场真实 3 条摘要，每条不超过 42 个汉字，一条只表达一个结论；
   - `minutesUrl` / `minutesFragments` / `placeholderImage`（session 级）：作为该场所有嘉宾的默认回退值，嘉宾级填写后优先使用嘉宾级。
   - 兼容说明：旧版单嘉宾字段 `speaker`/`companyRole` 仍被支持；新增数据请统一使用 `speakers` 数组。
3. 某场纪要未上线时，保留占位文案、`minutesUrl`/`minutesFragments` 留空——页面自动降级：摘要区显示占位说明，按钮显示“正式纪要将在大会后更新”。
4. 视频地址就绪后，填写 `videos[].url`（产品视频 / 企业家谈飞书 / 豆包工作发布）。
5. 空字段自动优雅隐藏，不出现空白按钮或破损图片。

## 四、埋点说明

统一埋点适配层 `trackEvent(name, payload)`：开发环境打印到 console；接入正式 SDK 时挂载 `window.__h5Tracker` 即可。

| 事件 | 触发时机 | 参数 |
|---|---|---|
| `hero_cta_click` | 点击“查看大会精华” | source |
| `track_select` | 切换内容标签 | track_id |
| `session_open` | 打开摘要抽屉 | session_id, track_id |
| `minutes_click` | 点击完整纪要 / 妙记片段 | session_id, status, fragment? |
| `brand_content_click` | 视频 / 文档 / 衔接引导条 | content_id, content_type |
| `takeaway_click` | 点击完整精华 / Skill | asset_type |
| `consult_click` | 点击预约飞书顾问 | source_section |

- **内容选择区（Section 02）**：底图与首屏保持一致（深红色渐变）；三个标签为单行导航（分段式滑动控件：白半透明框 + 蓝色选中滑块，副标题信息合并进下方环节说明行，不再换行）；同场多位嘉宾合并为一张卡（如“品牌领航 新质跃升”3 位嘉宾一张卡），每位嘉宾一行、各自“查看纪要”入口，点开即见该嘉宾独属的纪要卡片与妙记片段链接；议程卡片整体按比例缩小（标题 15px、嘉宾行 36px、职务单行省略），点击首屏“查看大会精华”跳转后，标签行及下方全部议程与底部蓝色引导按钮一屏内完整露出；切换不刷新页面、保留滚动位置。
- **摘要抽屉**：每位嘉宾 = 一张智能纪要卡片（示意图带“参考样式 / 非本次大会内容”遮罩）+ 一个“会议妙记片段”链接区；标题只出现一次；嘉宾姓名与职务各占一行（职务不换行，确实过长才允许折行）；占位态“3 个重点”只显示一条说明（不再三条重复文案）；占位态底部按钮为可点击的“深入了解飞书智能纪要”，点击关闭抽屉并平滑滚动到 Section 04；live 态按钮变为“打开 X 的飞书完整纪要”，直接打开该嘉宾妙记。
- **衔接引导**：内容区底部压缩后预留约 1/4 屏空间，设引导区“对刚才的纪要感兴趣？／摘要与妙记，都来自飞书智能会议纪要”+ 蓝色主按钮“深入了解飞书会议纪要”，点击平滑滚动到 Section 04 进入飞书能力区；首次关闭摘要抽屉后，底部浮出引导条“刚才的摘要，来自飞书智能会议纪要｜继续了解”，点击同样平滑滚动到 Section 04；Section 04→05、05→06 均以过渡文案衔接（“从纪要到协作”“大会精华可以带走，企业方案需要聊聊”）。

## 八、实现要点（规格合规）

- 设计基准 375px，内容最大宽度 720px；顶部适配 iOS 刘海屏（`env(safe-area-inset-top)`）。
- 品牌归因不打扰浏览：不再出现“技术由飞书 & 豆包工作提供”字样；摘要抽屉来源标注“由飞书智能会议纪要生成”、页脚“内容支持：飞书智能会议纪要｜主办单位：中国服装协会”保留。
- 品牌色 #1456F0 仅用于主按钮、选中态、链接与图标；正文不使用大面积品牌蓝，同屏仅一个高权重蓝色主按钮。
- 浅色区：背景 #FFFFFF / 分区 #F7F8FA / 主文字 #1F2329 / 次文字 #646A73 / 分割线 #DEE0E3；深色区与飞书品牌 KV 同色系。
- 字体为系统无衬线栈；按钮 48px 高、圆角 12px；卡片圆角 12px、1px 描边轻阴影；图标统一线性 SVG。
- 图片懒加载；尊重系统“减少动态效果”（`prefers-reduced-motion`）；点击目标 ≥ 44×44px。
